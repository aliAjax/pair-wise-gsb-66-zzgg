# 铁路轨道几何缺陷整治与复测平台

基于Vue3、Vuetify、Pinia、Vue Router、Apollo Client、GraphQL、Vite和TypeScript的独立前端工程，使用Canvas绘制里程图。业务数据本地持久化。

## 功能

- 区段、里程、轨距、高低、方向和三角坑检测数据。
- Canvas里程分布、超限点定位、缺陷三角标记和缩放。
- 缺陷筛选、批量派工、工区责任和重复缺陷关联。
- 打磨、捣固、更换、垫板调整等整治记录，复测轮次与关闭校验。
- 正式限速与临时限速冲突联查，区段版本递增。
- 离线补录队列：断网时整治、复测、关闭确认留在本机（localStorage），重开浏览器不丢失；跨窗口互斥入队与合并，每个补录事件只生效一次。
- 网络恢复后按现场记录时间合并；同编号复测保留原记录、补录列入待处理，后到数据不覆盖。
- 区段限速版本或缺陷版本变化后关闭结论重算，整治记录照旧保留，不通过回到复测不合格。
- 审计与导出区分已合并、待处理、冲突记录。

端口为`18466`。

```bash
npm install
npm run build
npm run dev
npm run verify  # 验证离线补录合并逻辑
```
